Asynchronous Programming with JavaScript

From synchronous execution to Promises, async/await, API requests, and error handling.

Learning outcomes

By the end of this lesson, students should be able to:

  • Distinguish synchronous and asynchronous execution.
  • Describe Promise states and handle Promise results.
  • Use async/await to fetch and process API data.
  • Handle network and HTTP errors with appropriate checks.

How setTimeout() Demonstrates Asynchronous Execution

The timer callback runs later, so the next synchronous statement appears first.

console.log("1. Request started");

setTimeout(() => {
  console.log("2. Announcement received");
}, 1000);

console.log("3. App continues");

Slide Demo 2

Handling Asynchronous Results with Promises

Register a callback for the HTTP response while JavaScript continues with other work.

console.log("1. Request started");

const request = fetch(API_URL);
request.then((response) => {
  console.log("2. Response received");
});

console.log("3. App continues");

Slide Demo 3

Make Asynchronous Code Easier to Follow

await pauses this async function while the request is pending, not the entire application.

async function loadAnnouncement() {
  const response = await fetch(API_URL);
  console.log("Response received");
}

loadAnnouncement();
console.log("App continues");

Slide Demo 4

From HTTP Response to Usable Data

Parse the response body and display useful properties from the returned post.

async function loadPost() {
  const response = await fetch(API_URL);
  const post = await response.json();

  console.log("Title:", post.title);
  console.log("Body:", post.body);
}

loadPost();

Slide Demo 5

Handling HTTP Errors and Network Failures

Check response.ok because fetch does not reject automatically for HTTP 404 or 500 responses.

async function loadPost(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) {
      throw new Error(`HTTP error: ${response.status}`);
    }

    const post = await response.json();
    console.log("Title:", post.title);
  } catch (error) {
    console.error("Could not load post:", error.message);
  }
}

loadPost(API_URL);

One reusable workflow across applications

Request data → Process and display results → Handle errors

  • Course registration: Retrieve courses and sections → Display available courses and times → Handle loading errors.
  • Online shopping: Load products and prices → Display products and calculate totals → Handle data errors.
  • Weather applications: Retrieve forecasts → Display weather conditions → Handle loading errors.

Practice 3

Understanding a pending Promise

The Promise stays pending while the timer waits, then becomes fulfilled when resolve() runs.

const request = new Promise((resolve) => {
  setTimeout(() => {
    resolve("Announcement received");
  }, 3000);
});

request.then((message) => console.log(message));
console.log("App continues");
